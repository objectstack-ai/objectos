# ObjectOS

**ObjectOS is the customer-hosted runtime for ObjectStack applications.**
It runs inside your environment — private cloud, customer data center, or
fully air-gapped network — loads a compiled `objectstack.json` artifact,
and serves the application APIs, metadata-driven UI, identity,
permissions, settings, automation, and integration surfaces described
by that artifact.

If you operate a regulated business, a private cloud, or any
infrastructure where customer data must stay inside your perimeter,
ObjectOS is what you deploy.

## Try it in two commands

```bash
npm i -g @objectstack/cli
os start
```

ObjectOS comes up at `http://localhost:3000` with an embedded database
and a sample application. See the [Quickstart](/docs/quickstart) for
Docker, desktop, and bring-your-own-database paths.

## What ObjectOS is

ObjectOS is the **runtime distribution** of ObjectStack:

- It runs compiled ObjectStack applications inside your infrastructure.
- It owns the customer-side HTTP runtime.
- It connects to the business database **you** configure for the project.
- It enforces authentication, permissions, row-level access, and field
  security when those capabilities are enabled.
- It exposes platform administration surfaces — users, roles, settings,
  sessions, audit logs, webhooks, diagnostics — through the Setup app.

## What ObjectOS is not

ObjectOS is not the low-code builder, not the control-plane database,
and not the protocol specification. Those belong to the ObjectStack
framework and cloud / control-plane layers.

The boundary is intentional:

| Layer | Responsibility |
|---|---|
| ObjectStack framework | Protocol, kernel, metadata model, drivers, services, plugins, SDKs |
| Control plane | Project authoring, artifact publishing, hostname / project resolution |
| **ObjectOS** | **Customer-hosted runtime that consumes artifacts and serves applications** |

In cloud-connected deployments, ObjectOS talks to the control plane
over the Artifact API. **It does not require direct access to the
control-plane database**, and in air-gapped deployments it does not
talk to the control plane at all.
