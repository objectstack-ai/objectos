# ObjectOS

**ObjectOS** is the reference runtime distribution of the
[ObjectStack framework](https://github.com/objectstack-ai/framework).
Customers run ObjectOS to serve their compiled project artifacts in
production — on a laptop, in a container, in Kubernetes, or fully
air-gapped.

## What this site covers

- **Install** — Docker, Helm, single-binary, bare metal.
- **Configure** — environment variables, plugin selection, business DB.
- **Upgrade** — version pinning, migration, rollback strategy.
- **Architecture** — how ObjectOS consumes Artifacts from the control plane.
- **Enterprise plugins** — SSO/SAML, SCIM, audit export, HA scheduling.

For **protocol references** (Object, Field, View, Flow, Agent, …), see
the upstream [ObjectStack docs](https://docs.objectstack.ai).
