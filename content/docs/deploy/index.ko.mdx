ObjectOS는 모든 환경에서 동일하게 실행되는 단일 런타임 아티팩트로 제공됩니다. 인프라에 맞는 배포 형태를 선택하세요.

## Docker

단일 컨테이너는 ObjectOS를 평가하거나 단일 호스트에서 실행하는 가장 빠른 방법입니다. 데이터 디렉터리용 볼륨을 마운트하고, 데이터베이스를 지정한 다음, 컨테이너를 시작하세요.

[Docker 가이드 →](/docs/deploy/docker)

## Kubernetes

프로덕션 환경에서는 ObjectOS를 Service 뒤의 Deployment로 실행하며, 데이터 디렉터리에 영구 스토리지를 사용하고 시크릿은 표준 Kubernetes 메커니즘을 통해 제공합니다.

[Kubernetes 가이드 →](/docs/deploy/kubernetes)

## Air-Gapped

인터넷 외부 통신이 없는 네트워크로 릴리스 번들을 반입하세요. ObjectOS는 로컬 파일에서 애플리케이션 아티팩트를 읽으며 호스팅된 서비스에 절대 접근하지 않습니다.

[에어갭 가이드 →](/docs/deploy/air-gapped)
