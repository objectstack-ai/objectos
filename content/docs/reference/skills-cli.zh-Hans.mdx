[`skills`](https://www.npmjs.com/package/skills) CLI（由 [vercel-labs/skills](https://github.com/vercel-labs/skills) 提供）是向 AI 编码 Agent 分发领域作用域指令的标准方式。ObjectOS 通过它发布 9 个官方 skill。

本页是参考卡片。概念性概览见 [Build → IDE Skills](/docs/build/ai-skills)。

## 安装

```bash
npx skills add objectstack-ai/framework
```

首次运行通过 `npx` 从 npm 下载 [`skills`](https://www.npmjs.com/package/skills) 包,然后从 [github.com/objectstack-ai/framework](https://github.com/objectstack-ai/framework) 拉取 skill 包(`skills/<name>/` 目录)并写入你的项目 Agent 配置。

任何时候重新运行以拉取最新版本。

## 写入什么

根据项目中存在的内容自动检测：

| Agent | 写入路径 |
|:--|:--|
| Claude Code | `.claude/skills/<name>/SKILL.md` |
| Cursor | `.cursor/rules/<name>.mdc` |
| GitHub Copilot | `.github/copilot-instructions.md`（合并） |
| Codex / Codex CLI | `AGENTS.md`（合并） |
| Gemini CLI | `.gemini/skills/<name>/` |
| Windsurf、Cline、Continue、Roo、Goose、Kiro、opencode…… | 其原生 skill / rules 格式 |

运行 `npx skills detect` 查看 CLI 计划写入什么。

## ObjectOS 发布什么

| Skill | 加载用于 |
|:--|:--|
| `objectstack-platform` | `defineStack`、驱动、适配器、插件、服务、`os` CLI、部署 |
| `objectstack-data` | `*.object.ts`、`*.seed.ts`、字段、关系、校验、索引、RLS、生命周期 Hook |
| `objectstack-query` | [ObjectQL](./objectql) —— 过滤、排序、分页、聚合、join、全文 |
| `objectstack-ui` | [视图](/docs/build/interface/views)、App、Page、Dashboard、Report、Chart、Action |
| `objectstack-automation` | 流程、Workflow、Trigger、审批、调度、webhook |
| `objectstack-ai` | Agent、Tool、Skill、对话、Model Registry、MCP |
| `objectstack-api` | REST/GraphQL 端点、auth、realtime、错误信封 |
| `objectstack-i18n` | 翻译包、locale 回退 |
| `objectstack-formula` | [CEL](./cel) 表达式 —— 公式字段、谓词、条件、调度 |

每个 skill 的 `SKILL.md` frontmatter 声明 Agent 何时应加载它,以及何时让位于同级。

## 常用命令

```bash
npx skills add <org>/<repo>        # 从 GitHub 仓库添加 skill 包
npx skills add <org>/<repo>@<ref>  # 钉到 tag / 分支 / SHA
npx skills list                    # 列出已安装 skill
npx skills remove <name>           # 移除 skill
npx skills detect                  # 显示 CLI 将写入哪些 Agent
npx skills --help                  # 完整选项
```

为可复现 CI 钉定版本：

```bash
npx skills add objectstack-ai/framework@v5.0.0
```

## 输出应提交在哪

**提交它。** Skill 是整个团队 —— 包括 CI Agent —— 都应共享的 markdown。CLI 写入标准 Agent 路径（`.claude/`、`.cursor/`、`AGENTS.md`……）,本来就该提交。

## 更新

```bash
npx skills add objectstack-ai/framework      # 拉取匹配 spec 版本范围的最新版本
```

升级 `@objectstack/spec` 后重新运行,使 Agent 与最新 Zod schema、CEL 辅助函数和元数据词汇保持同步。
