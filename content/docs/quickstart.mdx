# Quickstart

This guide brings ObjectOS up on a single machine so you can see the
runtime, the Setup app, and a working REST API. Use it for evaluation,
team demos, and validating that ObjectOS fits into your environment
before planning a production deployment.

For multi-node production, see the [Deployment Overview](/docs/deployment).

## Prerequisites

- **Node.js 20 or newer** — `node --version`
- **A terminal** with the ability to install global npm packages
- Optional: **Docker Desktop** if you prefer the container path below

No build step, no compilation, no source checkout required.

## Option A — Install the CLI and start (recommended)

The CLI ships a self-contained ObjectOS runtime that boots against the
bundled sample application. Two commands, no configuration:

```bash
npm i -g @objectstack/cli
os start
```

The runtime starts on `http://localhost:3000`. Open it in your browser.

```text
✓ ObjectOS started
  • Application:   http://localhost:3000
  • Setup app:     http://localhost:3000/_setup/
  • Data directory: ~/.objectstack
```

On first launch, ObjectOS provisions an embedded database under
`~/.objectstack` so you can explore without setting anything up. To
point it at your own database, see
[Runtime configuration](/docs/configure/runtime).

## Option B — Docker

If you prefer to evaluate inside a container, drop this file in an empty
directory as `docker-compose.yml`:

```yaml
services:
  objectos:
    image: ghcr.io/objectstack/objectos:latest
    ports: ["3000:3000"]
    volumes:
      - objectos-data:/var/lib/objectos

volumes:
  objectos-data: {}
```

Then:

```bash
docker compose up
```

ObjectOS is available at `http://localhost:3000`. To bring your own
artifact, mount it as `/artifacts/objectstack.json` and set
`OS_ARTIFACT_FILE=/artifacts/objectstack.json` — see
[Docker deployment](/docs/deploy/docker).

## Option C — Desktop app

For non-technical evaluators, ObjectOS also ships as a native desktop
application (macOS, Windows, Linux). Download from the
[releases page](https://github.com/objectstack-ai/objectos/releases),
install, launch. No terminal required.

## What you get out of the box

Once the runtime is up:

| Surface | URL | Purpose |
|---|---|---|
| Application | `/` | The metadata-driven UI defined by the loaded artifact |
| REST API | `/api/v1/...` | Generated CRUD endpoints for every object in the artifact |
| Setup app | `/_setup/` | Administer users, roles, settings, sessions, audit log, webhooks |
| Health | `/healthz` | Liveness probe for load balancers and Kubernetes |
