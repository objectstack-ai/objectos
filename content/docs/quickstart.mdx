# Quickstart

This page takes you from nothing installed to a running app you can
actually click around in. Total time: about a minute, assuming Node is
already on your machine.

## Prerequisites

- **Node.js 20 or newer** — `node --version`
- **pnpm** (recommended), npm, yarn, or bun
- A terminal

No build step. No Docker required. No account signup. No compilation of
source code.

## 1. Create a project

```bash
npx @objectstack/cli init my-app -t app --install
```

This scaffolds a minimal ObjectStack app, picks `pnpm` as your package
manager (auto-detected — override with `-p npm|yarn|bun`), and installs
dependencies. About 30 seconds on a warm cache.

You'll see:

```text
✓ Scaffold validated (namespace: my_app)
✓ Project initialized!

Next steps:
  cd my-app
  pnpm exec objectstack validate
  pnpm exec objectstack dev
```

## 2. Start the dev server

```bash
cd my-app
pnpm dev
```

Output:

```text
◆ Compile
  ✓ Build complete (462ms)
  Data: 1 Objects  3 Fields
  Artifact: dist/objectstack.json (2.0 KB)

◆ Development Mode
  ✓ Server is ready

  ➜  API:       http://localhost:3002/
  ➜  Studio:    http://localhost:3002/_studio/
  ➜  Account:   http://localhost:3002/_account/
  ➜  Console:   http://localhost:3002/_console/

  Driver:  SqlDriver(better-sqlite3) → ~/.objectstack/data/standalone.db
  Plugins: 23 loaded
```

The runtime watches `objectstack.config.ts` and `src/` — edit a file,
the kernel recompiles and reloads automatically.

## 3. Explore what's running

Open these in your browser:

| URL | What it is |
|---|---|
| http://localhost:3002/_account/register | Create your first account |
| http://localhost:3002/_studio/ | Browse and edit records (after login) |
| http://localhost:3002/_console/ | Users, roles, audit log, settings |
| http://localhost:3002/api/v1/data/example | Auto-generated REST API for the sample object |
| http://localhost:3002/health | Liveness probe |

The 4 surfaces share **one** identity store. Register once, you're
signed in across all of them.

## 4. Add your own object

Open `src/objects/` and add a TypeScript file:

```ts
// src/objects/task.ts
import { defineObject, f } from '@objectstack/spec';

export const task = defineObject({
  id: 'task',
  label: 'Task',
  fields: {
    title:     f.text({ required: true }),
    done:      f.boolean({ default: false }),
    due:       f.date(),
    assignee:  f.reference({ to: 'sys_user' }),
  },
});
```

Save. The dev server recompiles and you immediately have:

- **`/api/v1/data/task`** — full CRUD with filter/sort/paginate
- **A "Task" view in Studio** — list, form, detail, all generated
- **Permission rows in Console** — grant read/write per role
- **Audit log entries** — every create/update/delete recorded

No migrations. No code generation. No restarting.

## 5. Want a real app, not an empty one?

The [templates repo](https://github.com/objectstack-ai/templates) ships
production-shaped starters you can copy and customize:

| Template | What it is |
|---|---|
| `todo` | Universal task & project starter |
| `contracts` | Contract lifecycle (CLM) with AI extraction |
| `procurement` | Vendors, POs, 3-way match |
| `compliance` | SOC 2 / ISO 27001 controls + evidence |
| `helpdesk` | AI-first customer support |
| `content` | Editorial calendar + channel ROI |
| `hr` | Directory, org chart, time-off |

Each one is < 2500 LOC, readable in one sitting, runs standalone.

```bash
git clone https://github.com/objectstack-ai/templates.git
cd templates/packages/todo
pnpm install
pnpm dev    # http://localhost:4002
```

## What comes with `npx ... init`?

The scaffold gives you:

```text
my-app/
├── objectstack.config.ts    # Your stack definition (manifest + objects)
├── src/
│   └── objects/             # Your data model — add files here
├── dist/
│   └── objectstack.json     # Compiled artifact (regenerated on save)
├── package.json
└── tsconfig.json
```

Pre-installed plugins (loaded automatically by the runtime):

> Auth, Security (RBAC + RLS + FLS), Audit, REST API, Studio UI,
> Account UI, Console UI, AI Service, Queue, Jobs, Cache, Settings,
> Email, Storage, Marketplace, Metadata, ObjectQL, plus the SQL driver.

You don't import or wire any of these — they activate when your config
declares it needs them.
